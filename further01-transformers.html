11.1  From text to vectors

A tokenizer splits text into tokens and gives the ID of each token in the vocabulary. A token can be a whole word, part of a word, punctuation, or a piece that includes a space. The model uses each ID to look up a row in its embedding table EE. A vocabulary of nn tokens has nn rows. Each row holds dd learned numbers, the coordinates of that token's embedding. To represent a prompt, take one row for each token in the order it appears.

If 𝖻𝖺𝗇𝗄\textsf{bank} has the same ID in 𝗍𝗁𝖾 𝗋𝗂𝗏𝖾𝗋 𝖻𝖺𝗇𝗄\textsf{the river bank} and 𝗍𝗁𝖾 𝗌𝖺𝗏𝗂𝗇𝗀𝗌 𝖻𝖺𝗇𝗄\textsf{the savings bank}, both occurrences start with the same embedding. Training adjusts the entries of EE along with the maps that read these vectors. After attention incorporates the surrounding prefix, the two occurrences can have different hidden vectors.

11.2  Queries, keys, and values

Let X∈ℝm×dX\in\mathbb R^{m\times d} be the input to an attention head, with one row 𝐱i\mathbf x_i for each of the mm token positions. In a deeper layer, XX comes from earlier computations and may already carry information about many positions. The head applies three learned linear maps to every row. Leaving out optional biases, it forms Q=XWQ∈ℝm×d′,WQ∈ℝd×d′,K=XWK∈ℝm×d′,WK∈ℝd×d′,V=XWV∈ℝm×dv,WV∈ℝd×dv.\begin{align*} Q &= XW_Q \in \mathbb R^{m\times d'}, & W_Q &\in \mathbb R^{d\times d'},\\ K &= XW_K \in \mathbb R^{m\times d'}, & W_K &\in \mathbb R^{d\times d'},\\ V &= XW_V \in \mathbb R^{m\times d_v}, & W_V &\in \mathbb R^{d\times d_v}. \end{align*} At position ii, the three rows are the query 𝐪i=𝐱iWQ\mathbf q_i=\mathbf x_i W_Q, the key 𝐤i=𝐱iWK\mathbf k_i=\mathbf x_i W_K, and the value 𝐯i=𝐱iWV\mathbf v_i=\mathbf x_i W_V. Every query and key has width d′d', so we can take the dot (or inner) product of a query with any key in the head. The value 𝐯i\mathbf v_i can have a different width dvd_v.

How does a query score the keys? For a fixed query 𝐪i\mathbf q_i, the map 𝐤↦𝐪i⋅𝐤\mathbf k\mapsto\mathbf q_i\cdot\mathbf k is a linear functional. Its value 𝐪i⋅𝐤=∥𝐪i∥∥𝐤∥ρ\mathbf q_i\cdot\mathbf k= \|\mathbf q_i\|\,\|\mathbf k\|\,\rho combines the correlation ρ\rho of Remark 9.13, which measures alignment, with the lengths of the two vectors, in the head's learned coordinates. The query scores each eligible key 𝐤j\mathbf k_j by summing over all d′d' coordinates: 𝐪i⋅𝐤j=∑ℓ=1d′qiℓkjℓ\mathbf q_i\cdot\mathbf k_j=\sum_{\ell=1}^{d'}q_{i\ell}k_{j\ell}. For example, d′=128d'=128 in Llama 3 8B. Changing the query changes the coefficients in this sum and can change which key scores highest. The value 𝐯j\mathbf v_j carries the information contributed by source jj. This is self-attention because all three arrays come from the same sequence.

11.3  From scores to a contextual update

Scale, mask, and normalize. For full causal attention at position ii, sources are positions 1,…,i1,\ldots,i. After setting gij=sij/d′g_{ij}=s_{ij}/\sqrt{d'}, convert the eligible scores to weights by softmax aij={exp(gij)∑k=1iexp(gik),j≤i,0,j>i.a_{ij}= \begin{cases} \displaystyle\frac{\exp(g_{ij})}{\sum_{k=1}^{i}\exp(g_{ik})}, & j\le i,\\[4pt] 0, & j>i . \end{cases}(11.1) The causal mask excludes future positions from the denominator. Equivalently, set their scaled scores to −∞-\infty before softmax, using exp(−∞)=0\exp(-\infty)=0. When training on a sequence, row ii can then be used to predict token i+1i+1 without reading it. With no mask, the denominator instead sums over all mm positions.

Each row sums to 11 because the eligible numerators sum to the denominator. For eligible j,kj,k, aij/aik=exp(gij−gik)a_{ij}/a_{ik}=\exp(g_{ij}-g_{ik}). Thus score differences determine weight ratios. Adding a common constant to the eligible scores cancels in the ratios and leaves the row unchanged.

The scaling by 1/d′1/\sqrt{d'} has a variance motivation. In a simplified model where all coordinates of 𝐪\mathbf q and 𝐤\mathbf k are independent, each with mean 00 and variance 11, each product qℓkℓq_\ell k_\ell has mean 00 and second moment 1⋅1=11\cdot 1=1. Independence makes the variances add, giving Var(𝐪⋅𝐤)=d′\operatorname{Var}(\mathbf q\cdot\mathbf k)=d'. The scaled score then has variance 11. This motivates the scale used by Vaswani et al. (reference 1). Real trained activations can have different statistics.

Mix the values. Let A=(aij)A=(a_{ij}). The matrix Z=AVZ=AV is the output of the attention head. Its ii-th row 𝐳i\mathbf z_i is the weighted mixture of values delivered to position ii. Z=AV∈ℝm×dv,𝐳i=∑j=1iaij𝐯j.Z=AV\in\mathbb R^{m\times d_v},\qquad \mathbf z_i=\sum_{j=1}^{i}a_{ij}\mathbf v_j. Under the softmax in (11.1), this is a convex combination of eligible value vectors, since the weights are nonnegative and sum to 11. Each coordinate therefore lies between the smallest and largest corresponding eligible value coordinates. For fixed AA, mixing is linear in VV. As a function of XX, the head also computes the weights from XX. Each score is a sum of products of query and key coordinates, and softmax then makes the mixing weights depend nonlinearly on the scores.

11.4  From a head to a language model

Several heads and the residual stream. Suppose there are HH heads, each with value width dvd_v. Head hh produces the head output Zh=AhXWV,h∈ℝm×dvZ_h=A_h X W_{V,h}\in\mathbb R^{m\times d_v}. Here WV,h∈ℝd×dvW_{V,h}\in\mathbb R^{d\times d_v} is the learned value matrix used by head hh. Multiplying XX by WV,hW_{V,h} gives its value rows, and its attention matrix AhA_h mixes those rows. To combine the heads, concatenate their outputs side by side and apply a learned output matrix WO∈ℝHdv×dW_O\in\mathbb R^{Hd_v\times d}. Writing WO(h)W_O^{(h)} for row block hh of height dvd_v, block multiplication gives [Z1⋯ZH]WO=∑h=1HZhWO(h)=∑h=1HAhXWV,hWO(h).[\,Z_1\ \cdots\ Z_H\,]W_O =\sum_{h=1}^{H} Z_h W_O^{(h)} =\sum_{h=1}^{H} A_h X W_{V,h} W_O^{(h)}. Each term is m×dm\times d. Different heads can use different score tables and write different combinations of features into the same dd coordinates. The output of the attention sublayer is added to the incoming state, called the residual stream.

In one common design, a block normalizes each row before each sublayer. If RR denotes the incoming residual matrix and N1,N2N_1,N_2 are row-wise normalizations, the two residual updates have the form R1=R+Attention(N1(R)),R2=R1+MLP(N2(R1)).R_1=R+\operatorname{Attention}(N_1(R)),\qquad R_2=R_1+\operatorname{MLP}(N_2(R_1)). Attention lets one position draw on other positions. The feed-forward network, or MLP, acts separately on each row using the same weights at all positions. A simple bias-free example is MLP(Y)=ϕ(YW1)W2\operatorname{MLP}(Y)=\phi(YW_1)W_2, with W1∈ℝd×fW_1\in\mathbb R^{d\times f} and W2∈ℝf×dW_2\in\mathbb R^{f\times d} for intermediate width ff. An entrywise activation ϕ\phi makes the row map nonlinear in general. For example, take scalar weights W1=W2=(1)W_1=W_2=(1) and ϕ(t)=max(t,0)\phi(t)=\max(t,0). The result sends 11 to 11 and −1-1 to 00, violating linearity. The gated feed-forward network used in Llama 3 has the form (SiLU(YWg)⊙(YWa))Wb,SiLU(t)=t1+e−t.\bigl(\operatorname{SiLU}(YW_g)\odot (YW_a)\bigr)W_b,\qquad \operatorname{SiLU}(t)=\frac{t}{1+e^{-t}}. Here WgW_g and WaW_a both have size d×fd\times f, WbW_b has size f×df\times d, and ⊙\odot is entrywise multiplication. One projected branch modulates the other before the result is mapped back to width dd.

Readout and next-token probabilities. Let 𝐡i\mathbf h_i be the final row at position ii after any final normalization. A learned matrix U∈ℝd×nU\in\mathbb R^{d\times n} maps it to vocabulary scores, called logits. Label the columns of UU by the token IDs in the same order as the rows of EE, and let 𝒱\mathcal V be the set of these IDs. ℓi=𝐡iU,pi(t)=exp(ℓit)∑u∈𝒱exp(ℓiu).\boldsymbol\ell_i=\mathbf h_i U,\qquad p_i(t)=\frac{\exp(\ell_{it})}{\sum_{u\in\mathcal V}\exp(\ell_{iu})}. The column labeled tt scores token ID tt, and pip_i is a probability distribution on the vocabulary. In models with tied input and output weights, U=ETU=E^T. In attention, softmax distributes weight across positions in the current prefix. Here it distributes probability across vocabulary IDs. During generation, the last row scores the next token. A decoding rule can sample from the distribution or choose a highest-scoring token. The chosen ID is appended, and the process repeats on the longer prefix until a stopping condition is reached.

During ordinary generation the parameters stay fixed, while the hidden vectors and attention weights depend on the input.

11.5  What the linear algebra tells us about a head

The query–key product, rank, and null spaces. In the bias-free head without query/key rotations, the raw score matrix has the factorization S=XWQKXT,WQK=WQWKT∈ℝd×d,sij=𝐱iWQK𝐱jT.S=XW_{QK}X^T,\qquad W_{QK}=W_QW_K^T\in\mathbb R^{d\times d},\qquad s_{ij}=\mathbf x_i W_{QK}\mathbf x_j^T .(11.2) It follows by substituting Q=XWQQ=XW_Q and KT=WKTXTK^T=W_K^TX^T. This is a bilinear form, linear in either input with the other held fixed. It can represent a directional relation. In Example 11.3, for example, s31=2cs_{31}=2c and s13=0s_{13}=0 before masking. The two products apply different maps to the destination and source.

The map 𝐱↦𝐱WQK\mathbf x\mapsto\mathbf xW_{QK} factors through the d′d' entries of 𝐱WQ\mathbf xW_Q, so rankWQK≤d′\operatorname{rank}W_{QK}\le d'. Which changes to a source row leave every score unchanged? Adding 𝐮\mathbf u to 𝐱j\mathbf x_j changes the score by 𝐱iWQK𝐮T\mathbf x_iW_{QK}\mathbf u^T. This vanishes for every destination row exactly when WQK𝐮T=0W_{QK}\mathbf u^T=0. By the rank theorem (Theorem 7.9), the space of such source directions has dimension d−rankWQKd-\operatorname{rank}W_{QK}. For a change 𝐮\mathbf u to the destination row, the corresponding condition is 𝐮WQK=0\mathbf uW_{QK}=0. A direction invisible in a source score can still affect the value sent by that source.

11.6  Position, normalization, and efficient attention

Position as a rotation. Position has the same meaning as in Section 11.1. In 𝖣𝗈𝗀𝗌 𝗇𝖾𝖺𝗋 𝗍𝗋𝖺𝖿𝖿𝗂𝖼\textsf{Dogs near traffic}, a query from 𝗍𝗋𝖺𝖿𝖿𝗂𝖼\textsf{traffic} has token position i=3i=3 and a key from 𝖣𝗈𝗀𝗌\textsf{Dogs} has token position j=1j=1. The key is i−j=2i-j=2 tokens back. Additive encoding uses the token position to select a vector to add to the embedding. Rotary position embedding (RoPE, reference 5) uses that same position to set rotation angles inside the query and key. For a row (a,b)(a,b), right multiplication by the 2×22\times2 matrix D(α)=(cosαsinα−sinαcosα)D(\alpha)=\begin{pmatrix} \cos\alpha&\sin\alpha\\ -\sin\alpha&\cos\alpha \end{pmatrix} rotates that pair counterclockwise through angle α\alpha. Write the query at token position ii as 𝐪i=(qi,1,qi,2,…,qi,d′)\mathbf q_i=(q_{i,1},q_{i,2},\ldots,q_{i,d'}). The first index identifies the token position and the second identifies a coordinate within that query. For the first rotation block, take 𝐮=(qi,1,qi,2)\mathbf u=(q_{i,1},q_{i,2}) from this single query and 𝐯=(kj,1,kj,2)\mathbf v=(k_{j,1},k_{j,2}) from the key at position jj, ordering coordinates by rotation block. Use the same angle step θ\theta for both pairs. Since D(β)T=D(−β)D(\beta)^T=D(-\beta) and rotations in the plane add angles, (𝐮D(iθ))(𝐯D(jθ))T=𝐮D((i−j)θ)𝐯T.(\mathbf uD(i\theta))(\mathbf vD(j\theta))^T =\mathbf uD((i-j)\theta)\mathbf v^T. For example, if 𝐮=𝐯=(1,0)\mathbf u=\mathbf v=(1,0) and θ=π/2\theta=\pi/2, this pair contributes 11 at equal positions, 00 one step back, and −1-1 two steps back.

Now take full query and key rows of even width d′=2rd'=2r. Group their coordinates into rr matching pairs and give pair aa its own angle step θa\theta_a. Thus ii counts tokens along the prompt, and aa counts coordinate pairs within one token's vector. The full rotation at position ii is the d′×d′d'\times d' block diagonal matrix R(i)=diag(D(iθ1),…,D(iθr)).R(i)=\operatorname{diag}\bigl(D(i\theta_1),\ldots,D(i\theta_r)\bigr). For d′=128d'=128, for example, there are 6464 two-dimensional blocks. The full query and key become 𝐪iR(i)\mathbf q_iR(i) and 𝐤jR(j)\mathbf k_jR(j). Their dot product adds the contributions from all rr pairs. Applying the two-dimensional identity block by block gives R(i)R(j)T=R(i−j)R(i)R(j)^T=R(i-j), so the full raw score is (𝐪iR(i))(𝐤jR(j))T=𝐪iR(i−j)𝐤jT.(\mathbf q_iR(i))(\mathbf k_jR(j))^T =\mathbf q_i R(i-j)\mathbf k_j^T. Thus the effective bilinear matrix is WQR(i−j)WKTW_QR(i-j)W_K^T. It can vary with the relative position i−ji-j, so the fixed WQKW_{QK} in (11.2) describes the unrotated case. The raw score table still has rank at most d′d' because it is the product of the rotated query matrix and the transpose of the rotated key matrix. The arbitrary change of coordinates above need not preserve these rotated scores, since MR(i−j)M−1MR(i-j)M^{-1} can differ from R(i−j)R(i-j).

Normalization and orthogonal projection. LayerNorm first centers a row 𝐱\mathbf x by subtracting its mean from every entry. In matrix form the centered row is 𝐱C\mathbf x C, where C=Id−1T1/dC=I_d-\mathbf 1^T\mathbf 1/d and 1=(1,…,1)\mathbf 1=(1,\ldots,1) has length dd. Since 𝐱C\mathbf xC has entry sum 00 and 𝐱−𝐱C\mathbf x-\mathbf xC is a multiple of 1\mathbf 1, Theorem 9.29 shows that 𝐱C\mathbf xC is the orthogonal projection onto 1⊥\mathbf 1^\perp. LayerNorm then divides by ∥𝐱C∥2/d+ε\sqrt{\|\mathbf x C\|^2/d+\varepsilon} and typically applies learned coordinate-wise gains and offsets. The centering is linear. The division depends on the input and is nonlinear.

RMSNorm (reference 6) skips centering. Before the learned coordinate-wise gains it computes 𝐱/∥𝐱∥2/d+ε\mathbf x/\sqrt{\|\mathbf x\|^2/d+\varepsilon}. For 𝐱=(1,3)\mathbf x=(1,3), the LayerNorm centering gives (−1,1)(-1,1) and the RMSNorm numerator is (1,3)(1,3). In the limit ε→0+\varepsilon\to0^+ and before learned gains and offsets, the respective results are (−1,1)(-1,1) and (1,3)/5(1,3)/\sqrt5. The stabilizer ε>0\varepsilon>0 keeps the denominator positive, even when the numerator is zero.

Grouped-query attention and the key–value cache. In deterministic inference with the row-wise blocks above, a prefix keeps its hidden states when another token is appended, provided earlier position encodings and mask entries stay fixed. To see this, start with the unchanged input embeddings of the prefix. In each block an old row reads only old rows, and its normalization, MLP, and residual update take the same inputs as before. Inducting over the blocks shows that the keys and values for those positions can be saved in a KV cache. The new position computes its own query and compares it to the permitted stored keys and its new key. It then mixes the corresponding values.

In grouped-query attention (GQA), several query heads share one pair of key and value arrays. Their distinct query matrices can still produce distinct weight rows. For example, Meta's Llama 3 8B has width 40964096, 3232 query heads, and 88 key–value heads (reference 7, Table 3). Each head has width 4096/32=1284096/32=128, so one query head uses a 4096×1284096\times128 query matrix. Four query heads share each key–value head. For a prefix of mm tokens, the cache holds 2m⋅8⋅1282m\cdot8\cdot128 scalars per layer, one array each for keys and values. This is one quarter of the cache for 3232 independent key–value heads of the same width.

11.7  What public descriptions say about major models

The calculations above describe a reference text decoder. Published systems use this mathematical pattern with model-specific choices about which rows are visible, which heads share weights, and how each row's features are transformed.

  • OpenAI and ChatGPT. GPT-4 was first offered to ChatGPT Plus subscribers, in March 2023. OpenAI's technical report describes it as Transformer-style and pretrained to predict the next token. The report withholds detailed architecture specifications, including model size. OpenAI's separately released gpt-oss models give inspectable examples. Their model card documents grouped-query attention, rotary embeddings, and alternating local-window and full causal attention. Each head also has a learned scalar bb. If the eligible token scores have total exponential weight T=∑jegijT=\sum_j e^{g_{ij}}, the implementation divides each egije^{g_{ij}} by T+ebT+e^b. The token weights sum to T/(T+eb)<1T/(T+e^b)<1. The remaining weight can be assigned to a zero value, so the convex hull for this mixture includes the origin. In the feed-forward block, an affine map of each normalized token row scores the experts. Softmax over the four largest scores weights their outputs. (References 8–10.)
  • Anthropic and Claude. Anthropic's public study of Claude 3.5 Haiku examined a prompt asking for the capital of the state containing Dallas. The model answered Austin. Feature interventions supported a pathway through features associated with Texas. In constructing the attribution graph, the authors held the prompt's attention weights fixed. This lets them trace what information travels along a weighted connection while leaving open how the queries and keys produced that weight. Anthropic's earlier work develops the query–key and output–value factorization used here. (References 2–3.)
  • Meta and Llama. The Llama 3 report gives a concrete architecture with grouped-query attention, RoPE, and a gated feed-forward activation called SwiGLU. It specifies dimensions and head counts, so the matrix shapes in the preceding sections can be compared with those of a trained model. (Reference 7, Section 3.2.)
