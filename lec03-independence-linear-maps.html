3.1  Homogeneous systems and the structure of solution sets

💡 Intuition

Among all right-hand sides, one is special: 𝐛=0\mathbf{b} = \mathbf{0}. A system with zero right-hand side can never be inconsistent — the zero vector always solves it — so the interesting question flips from whether solutions exist to how many. And, as we are about to prove, whoever understands A𝐱=0A\mathbf{x} = \mathbf{0} understands every A𝐱=𝐛A\mathbf{x} = \mathbf{b}: the two solution sets differ only by a shift.

Definition 3.1 (Homogeneous system)¶

A linear system of the form A𝐱=0A\mathbf{x} = \mathbf{0} is called homogeneous. It is always consistent, since 𝐱=0\mathbf{x} = \mathbf{0} is a solution — the trivial solution. The interesting question is whether a nonzero solution exists.

Example 3.2 (Solving a homogeneous system)¶

Let A=(1203241836111)with columns 𝐚1,𝐚2,𝐚3,𝐚4.A = \begin{pmatrix} 1 & 2 & 0 & 3 \\ 2 & 4 & 1 & 8 \\ 3 & 6 & 1 & 11 \end{pmatrix} \qquad\text{with columns } \mathbf{a}_1, \mathbf{a}_2, \mathbf{a}_3, \mathbf{a}_4 . Row reduction (R2−2R1R_2 - 2R_1, R3−3R1R_3 - 3R_1, then R3−R2R_3 - R_2) brings the augmented matrix of A𝐱=0A\mathbf{x} = \mathbf{0} to reduced echelon form: \begin{amatrix} 1 & 2 & 0 & 3 & 0 \\ 2 & 4 & 1 & 8 & 0 \\ 3 & 6 & 1 & 11 & 0 \end{amatrix} \xrightarrow{\substack{R_2 - 2R_1 \\ R_3 - 3R_1 \\ R_3 - R_2}} \begin{amatrix} 1 & 2 & 0 & 3 & 0 \\ 0 & 0 & 1 & 2 & 0 \\ 0 & 0 & 0 & 0 & 0 \end{amatrix} Pivots in columns 11 and 33; the variables x2=sx_2 = s and x4=tx_4 = t are free. The parametric vector form of the solutions of A𝐱=0A\mathbf{x} = \mathbf{0} is 𝐱=s(−2100)+t(−30−21),s,t∈ℝ\mathbf{x} = s \begin{pmatrix} -2 \\ 1 \\ 0 \\ 0 \end{pmatrix} + t \begin{pmatrix} -3 \\ 0 \\ -2 \\ 1 \end{pmatrix}, \qquad s, t \in \mathbb{R} — a plane through the origin inside ℝ4\mathbb{R}^4, with one direction vector per free variable. Note there is no ``particular solution'' vector out front: for a homogeneous system the trivial solution plays that role. Keep this example; it works overtime in this lecture.

Theorem 3.3 (Solution sets of A𝐱=𝐛A\mathbf{x} = \mathbf{b} and A𝐱=0A\mathbf{x} = \mathbf{0})¶

Suppose A𝐱=𝐛A\mathbf{x} = \mathbf{b} is consistent and let 𝐩\mathbf{p} be one particular solution. Then the solution set of A𝐱=𝐛A\mathbf{x} = \mathbf{b} is exactly {𝐩+𝐡:𝐡 is a solution of A𝐱=0}.\{\, \mathbf{p} + \mathbf{h} \;:\; \mathbf{h} \text{ is a solution of } A\mathbf{x} = \mathbf{0} \,\}. In words: the solution set of A𝐱=𝐛A\mathbf{x} = \mathbf{b} is the solution set of the homogeneous system translated by 𝐩\mathbf{p}.

Both directions come from linearity. If A𝐡=0A\mathbf{h} = \mathbf{0}, then A(𝐩+𝐡)=A𝐩+A𝐡=𝐛+0=𝐛A(\mathbf{p} + \mathbf{h}) = A\mathbf{p} + A\mathbf{h} = \mathbf{b} + \mathbf{0} = \mathbf{b}, so 𝐩+𝐡\mathbf{p} + \mathbf{h} is a solution. Conversely, if A𝐰=𝐛A\mathbf{w} = \mathbf{b}, set 𝐡=𝐰−𝐩\mathbf{h} = \mathbf{w} - \mathbf{p}; then A𝐡=A𝐰−A𝐩=𝐛−𝐛=0A\mathbf{h} = A\mathbf{w} - A\mathbf{p} = \mathbf{b} - \mathbf{b} = \mathbf{0}, so 𝐰=𝐩+𝐡\mathbf{w} = \mathbf{p} + \mathbf{h} with 𝐡\mathbf{h} a homogeneous solution.

□
Example 3.4 (Translation in action)¶

Continue with the matrix AA of the homogeneous example, and take 𝐛=𝐚1+𝐚3=(134)T\mathbf{b} = \mathbf{a}_1 + \mathbf{a}_3 = \begin{pmatrix} 1 & 3 & 4 \end{pmatrix}^{T}. By the column view, 𝐩=(1010)T\mathbf{p} = \begin{pmatrix} 1 & 0 & 1 & 0 \end{pmatrix}^{T} is a particular solution of A𝐱=𝐛A\mathbf{x} = \mathbf{b}, and by the structure theorem the complete solution set is 𝐱=(1010)+s(−2100)+t(−30−21),s,t∈ℝ\mathbf{x} = \begin{pmatrix} 1 \\ 0 \\ 1 \\ 0 \end{pmatrix} + s \begin{pmatrix} -2 \\ 1 \\ 0 \\ 0 \end{pmatrix} + t \begin{pmatrix} -3 \\ 0 \\ -2 \\ 1 \end{pmatrix}, \qquad s, t \in \mathbb{R} — the same plane of homogeneous solutions, shifted by 𝐩\mathbf{p}. Compare with Lecture 2's parametric example: the “particular solution plus direction vectors” shape we computed there was not an accident; it is the structure theorem in action.

3.2  Linear independence

💡 Intuition

When does a collection of vectors contain redundancy — one vector expressible from the others? The column view turns this qualitative question into a computation: pack the vectors as the columns of a matrix AA; redundancy is exactly a nonzero solution of A𝐱=0A\mathbf{x} = \mathbf{0}. The homogeneous machinery of the last section thus becomes a redundancy detector.

Definition 3.5 (Linear independence)¶

Vectors 𝐯1,…,𝐯n∈ℝm\mathbf{v}_1, \dots, \mathbf{v}_n \in \mathbb{R}^m are linearly independent if the only weights with x1𝐯1+x2𝐯2+⋯+xn𝐯n=0x_1 \mathbf{v}_1 + x_2 \mathbf{v}_2 + \cdots + x_n \mathbf{v}_n = \mathbf{0} are x1=x2=⋯=xn=0x_1 = x_2 = \cdots = x_n = 0. They are linearly dependent if such a combination exists with at least one weight nonzero.

Proposition 3.6 (Independence as a homogeneous system)¶

Let A=(𝐯1𝐯2⋯𝐯n)A = \begin{pmatrix} \mathbf{v}_1 & \mathbf{v}_2 & \cdots & \mathbf{v}_n \end{pmatrix} be the m×nm \times n matrix with the given vectors as columns. Then 𝐯1,…,𝐯n\mathbf{v}_1, \dots, \mathbf{v}_n are linearly dependent if and only if A𝐱=0A\mathbf{x} = \mathbf{0} has a nonzero solution.

By the column view, A𝐱=x1𝐯1+⋯+xn𝐯nA\mathbf{x} = x_1\mathbf{v}_1 + \cdots + x_n\mathbf{v}_n. So a nonzero solution of A𝐱=0A\mathbf{x} = \mathbf{0} is a dependence relation with some weight nonzero, and conversely.

□
Example 3.7 (Reading dependence off the null space)¶

Return to the homogeneous example. Each direction vector of the solution set is, by the proposition, a dependence relation among the columns of AA. Taking s=1,t=0s = 1, t = 0: −2𝐚1+𝐚2=0-2\mathbf{a}_1 + \mathbf{a}_2 = \mathbf{0}, i.e. 𝐚2=2𝐚1\mathbf{a}_2 = 2\mathbf{a}_1. Taking s=0,t=1s = 0, t = 1: −3𝐚1−2𝐚3+𝐚4=0-3\mathbf{a}_1 - 2\mathbf{a}_3 + \mathbf{a}_4 = \mathbf{0}, i.e. 𝐚4=3𝐚1+2𝐚3\mathbf{a}_4 = 3\mathbf{a}_1 + 2\mathbf{a}_3. This is the general pattern: the parametric vector form of A𝐱=0A\mathbf{x} = \mathbf{0} shows exactly how each column of AA without a pivot is a linear combination of the pivot columns — one direction vector per non-pivot column, with the dependence weights visible in its entries.

Theorem 3.8 (Wide matrices have nonzero null solutions)¶

Let AA be an m×nm \times n matrix. If n>mn > m (more columns than rows), then A𝐱=0A\mathbf{x} = \mathbf{0} has a nonzero solution.

Bring the augmented matrix (A∣0)(\,A \mid \mathbf{0}\,) to echelon form. Each pivot occupies its own row, so there are at most mm pivots. By part (3) of the existence–uniqueness theorem, the number of free variables is nn minus the number of pivots, which is at least n−m>0n - m > 0: a free variable exists. The system is consistent (it is homogeneous), so setting that free variable equal to 11 and solving produces a solution with a nonzero entry.

□
Corollary 3.9 (Too many vectors are dependent)¶

Any nn vectors in ℝm\mathbb{R}^m with n>mn > m are linearly dependent.

Pack the vectors as the columns of an m×nm \times n matrix AA. Since n>mn > m, the theorem gives a nonzero solution of A𝐱=0A\mathbf{x} = \mathbf{0}, which by the proposition is a dependence relation.

□

3.3  Linear maps and their matrices

💡 Intuition

A matrix does not just store a system — it acts: feed it a vector 𝐱\mathbf{x}, receive a vector A𝐱A\mathbf{x}. Machines of this kind — functions sending vectors to vectors while respecting vector arithmetic — are everywhere in engineering: rotations, reflections, projections, coordinate changes, linear filters. This section defines them, and then proves something remarkable: they are exactly the matrices, no more and no less.

Definition 3.10 (Linear map)¶

A function T:ℝn→ℝmT\colon \mathbb{R}^n \to \mathbb{R}^m is a linear map (or linear transformation) if for all 𝐮,𝐯∈ℝn\mathbf{u}, \mathbf{v} \in \mathbb{R}^n and all scalars c∈ℝc \in \mathbb{R}: T(𝐮+𝐯)=T(𝐮)+T(𝐯)andT(c𝐮)=cT(𝐮).T(\mathbf{u} + \mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v}) \qquad\text{and}\qquad T(c\,\mathbf{u}) = c\,T(\mathbf{u}). Equivalently: TT turns linear combinations of inputs into the same linear combinations of outputs. Applying the two rules repeatedly — first to the sum, then to each scalar multiple — gives, for any vectors 𝐮1,…,𝐮t∈ℝn\mathbf{u}_1, \dots, \mathbf{u}_t \in \mathbb{R}^n and any scalars x1,…,xtx_1, \dots, x_t, T(x1𝐮1+x2𝐮2+⋯+xt𝐮t)=x1T(𝐮1)+x2T(𝐮2)+⋯+xtT(𝐮t),T(x_1 \mathbf{u}_1 + x_2 \mathbf{u}_2 + \cdots + x_t \mathbf{u}_t) = x_1 T(\mathbf{u}_1) + x_2 T(\mathbf{u}_2) + \cdots + x_t T(\mathbf{u}_t), so a linear map is pinned down by its values on vectors from which every input can be combined — an observation that will shortly hand us the matrix of TT.

Example 3.11 (Every matrix gives a linear map)¶

For any m×nm \times n matrix AA, the function T(𝐱)=A𝐱T(\mathbf{x}) = A\mathbf{x} is a linear map from ℝn\mathbb{R}^n to ℝm\mathbb{R}^m: the two requirements are precisely the linearity theorem of Lecture 1. So every matrix defines a linear map. The rest of this section shows the converse.

Example 3.12 (Rotation of the plane)¶

Fix an angle θ\theta and let T:ℝ2→ℝ2T\colon \mathbb{R}^2 \to \mathbb{R}^2 rotate every vector counterclockwise by θ\theta about the origin. This is a linear map, for geometric reasons: rotating a parallelogram rotates its diagonal, so T(𝐮+𝐯)=T(𝐮)+T(𝐯)T(\mathbf{u} + \mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v}); and rotating a stretched arrow is the same as stretching the rotated arrow, so T(c𝐮)=cT(𝐮)T(c\mathbf{u}) = c\,T(\mathbf{u}).

Here is the same map in coordinates (see the figure below). Let 𝐮=(xy)T\mathbf{u} = \begin{pmatrix} x & y \end{pmatrix}^{T} have length rr and make angle φ\varphi with the positive xx-axis, so x=rcosφx = r\cos\varphi and y=rsinφy = r\sin\varphi. Rotation keeps the length and adds θ\theta to the angle, so T(𝐮)T(\mathbf{u}) has length rr and angle φ+θ\varphi + \theta. Expanding with the angle-addition formulas and then substituting x=rcosφx = r\cos\varphi, y=rsinφy = r\sin\varphi: T(𝐮)=(rcos(φ+θ)rsin(φ+θ))=(rcosφcosθ−rsinφsinθrsinφcosθ+rcosφsinθ)=(xcosθ−ysinθxsinθ+ycosθ).\begin{aligned} T(\mathbf{u}) &= \begin{pmatrix} r\cos(\varphi+\theta) \\ r\sin(\varphi+\theta) \end{pmatrix} = \begin{pmatrix} r\cos\varphi\cos\theta - r\sin\varphi\sin\theta \\ r\sin\varphi\cos\theta + r\cos\varphi\sin\theta \end{pmatrix} \\ &= \begin{pmatrix} x\cos\theta - y\sin\theta \\ x\sin\theta + y\cos\theta \end{pmatrix}. \end{aligned} The last vector is a matrix–vector product. Define the rotation matrix Rθ=(cosθ−sinθsinθcosθ).R_\theta = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}. Then T(xy)=(cosθ−sinθsinθcosθ)(xy)=Rθ𝐮.T\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix} \begin{pmatrix} x \\ y \end{pmatrix} = R_\theta\,\mathbf{u} . So rotation by θ\theta is the matrix map 𝐱↦Rθ𝐱\mathbf{x} \mapsto R_\theta \mathbf{x} — trigonometry packed into four entries — and by the previous example it is linear, which confirms the geometric argument algebraically. (Check with θ=90∘\theta = 90^\circ: R90∘=(0−110)R_{90^\circ} = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix} sends (10)T\begin{pmatrix} 1 & 0 \end{pmatrix}^{T} to (01)T\begin{pmatrix} 0 & 1 \end{pmatrix}^{T}, a quarter turn.)

Example 3.13 (Flipping around a line in ℝ3\mathbb{R}^3)¶

Let T:ℝ3→ℝ3T\colon \mathbb{R}^3 \to \mathbb{R}^3 flip space around the zz-axis — that is, rotate by 180∘180^\circ about the line of all (00z)T\begin{pmatrix} 0 & 0 & z \end{pmatrix}^{T}. A point's zz-coordinate is untouched while its (x,y)(x,y)-part is sent to the opposite side: T(xyz)=(−x−yz).T\begin{pmatrix} x \\ y \\ z \end{pmatrix} = \begin{pmatrix} -x \\ -y \\ z \end{pmatrix}. From this formula, linearity is an entrywise check: negating and copying entries both respect addition and scaling. Flips around other lines are also linear maps; this one has the friendliest formula because its line is a coordinate axis.

Definition 3.14 (Standard basis vectors)¶

The standard basis vectors of ℝn\mathbb{R}^n are the columns 𝐞1,…,𝐞n\mathbf{e}_1, \dots, \mathbf{e}_n of zeros with a single 11: the jj-th entry of 𝐞j\mathbf{e}_j is 11 and all other entries are 00. Every vector decomposes as 𝐱=x1𝐞1+x2𝐞2+⋯+xn𝐞n\mathbf{x} = x_1 \mathbf{e}_1 + x_2 \mathbf{e}_2 + \cdots + x_n \mathbf{e}_n — read the entries as weights.

Theorem 3.15 (The matrix of a linear map)¶

Let T:ℝn→ℝmT\colon \mathbb{R}^n \to \mathbb{R}^m be a linear map. Then there is exactly one m×nm \times n matrix AA with T(𝐱)=A𝐱for all 𝐱∈ℝn,T(\mathbf{x}) = A\mathbf{x} \qquad\text{for all } \mathbf{x} \in \mathbb{R}^n, namely the matrix whose jj-th column is T(𝐞j)T(\mathbf{e}_j): A=(T(𝐞1)T(𝐞2)⋯T(𝐞n)).A = \begin{pmatrix} T(\mathbf{e}_1) & T(\mathbf{e}_2) & \cdots & T(\mathbf{e}_n) \end{pmatrix}. AA is called the matrix of TT (or the standard matrix).

Existence. Let AA be the matrix displayed above and take any 𝐱∈ℝn\mathbf{x} \in \mathbb{R}^n. Decompose 𝐱=x1𝐞1+⋯+xn𝐞n\mathbf{x} = x_1\mathbf{e}_1 + \cdots + x_n\mathbf{e}_n as in the definition. Applying TT and using linearity repeatedly (first on the sum, then on each scalar multiple), T(𝐱)=x1T(𝐞1)+x2T(𝐞2)+⋯+xnT(𝐞n),T(\mathbf{x}) = x_1 T(\mathbf{e}_1) + x_2 T(\mathbf{e}_2) + \cdots + x_n T(\mathbf{e}_n), and by the column view this linear combination of the columns of AA with weights x1,…,xnx_1, \dots, x_n is exactly A𝐱A\mathbf{x}.

Uniqueness. Suppose A𝐱=B𝐱A\mathbf{x} = B\mathbf{x} for all 𝐱\mathbf{x}. Taking 𝐱=𝐞j\mathbf{x} = \mathbf{e}_j picks out the jj-th columns: A𝐞j=B𝐞jA\mathbf{e}_j = B\mathbf{e}_j says the jj-th columns of AA and BB agree, for every jj. Hence A=BA = B: no other matrix represents TT.

□
Corollary 3.16 (Matrices ↔\leftrightarrow linear maps)¶

Every m×nm \times n matrix defines a linear map ℝn→ℝm\mathbb{R}^n \to \mathbb{R}^m (via 𝐱↦A𝐱\mathbf{x} \mapsto A\mathbf{x}), and every linear map ℝn→ℝm\mathbb{R}^n \to \mathbb{R}^m is defined by exactly one m×nm \times n matrix (the theorem). So there is a one-to-one correspondence {m×n matrices}↔{linear maps ℝn→ℝm}.\{\, m \times n \text{ matrices} \,\} \;\longleftrightarrow\; \{\, \text{linear maps } \mathbb{R}^n \to \mathbb{R}^m \,\}. Matrices and linear maps are two descriptions of the same objects: the matrix is the data, the map is the action. To find the matrix of any linear map, feed it the standard basis vectors and record the outputs as columns.

Example 3.17 (The rotation matrix, by the recipe)¶

Apply the recipe to rotation by θ\theta. Rotating 𝐞1\mathbf{e}_1 (which points along the positive xx-axis) by θ\theta lands on (cosθsinθ)T\begin{pmatrix} \cos\theta & \sin\theta \end{pmatrix}^{T}; rotating 𝐞2\mathbf{e}_2 lands on (−sinθcosθ)T\begin{pmatrix} -\sin\theta & \cos\theta \end{pmatrix}^{T}. By the theorem, the matrix of the rotation is (T(𝐞1)T(𝐞2))=(cosθ−sinθsinθcosθ)=Rθ,\begin{pmatrix} T(\mathbf{e}_1) & T(\mathbf{e}_2) \end{pmatrix} = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix} = R_\theta , exactly the matrix found by trigonometry in the rotation example — as it must be, since the theorem says only one matrix represents TT. Notice how much less work the recipe took: two special inputs instead of a general one, and no angle-addition formulas.

Example 3.18 (The flip matrix)¶

For the flip around the zz-axis: T(𝐞1)=−𝐞1T(\mathbf{e}_1) = -\mathbf{e}_1, T(𝐞2)=−𝐞2T(\mathbf{e}_2) = -\mathbf{e}_2, and T(𝐞3)=𝐞3T(\mathbf{e}_3) = \mathbf{e}_3. So its matrix is F=(−1000−10001),F = \begin{pmatrix} -1 & 0 & 0 \\ 0 & -1 & 0 \\ 0 & 0 & 1 \end{pmatrix}, and indeed F(xyz)T=(−x−yz)TF \begin{pmatrix} x & y & z \end{pmatrix}^{T} = \begin{pmatrix} -x & -y & z \end{pmatrix}^{T}.

3.4  Injective, surjective, and bijective maps

💡 Intuition

Two questions can be asked of any function: does it ever send two different inputs to the same output, and does it reach every possible output? For a linear map T(𝐱)=A𝐱T(\mathbf{x}) = A\mathbf{x} these are not new questions at all — they are uniqueness and existence for A𝐱=𝐛A\mathbf{x} = \mathbf{b}, the subject of Lecture 2, asked of every 𝐛\mathbf{b} at once. So both answers are read off the pivots of AA: uniqueness lives in the columns, existence in the rows.

Definition 3.19 (Injective, surjective, bijective)¶

Let T:ℝn→ℝmT\colon \mathbb{R}^n \to \mathbb{R}^m be a function.

  • TT is injective (or one-to-one) if distinct inputs have distinct outputs: whenever T(𝐮)=T(𝐯)T(\mathbf{u}) = T(\mathbf{v}), then 𝐮=𝐯\mathbf{u} = \mathbf{v}.
  • TT is surjective (or onto) if every target vector is hit: for each 𝐛∈ℝm\mathbf{b} \in \mathbb{R}^m there is at least one 𝐱∈ℝn\mathbf{x} \in \mathbb{R}^n with T(𝐱)=𝐛T(\mathbf{x}) = \mathbf{b}.
  • TT is bijective if it is both — equivalently, every 𝐛∈ℝm\mathbf{b} \in \mathbb{R}^m equals T(𝐱)T(\mathbf{x}) for exactly one 𝐱∈ℝn\mathbf{x} \in \mathbb{R}^n.

Theorem 3.20 (Injectivity and surjectivity through the matrix)¶

Let AA be an m×nm \times n matrix, let T:ℝn→ℝmT\colon \mathbb{R}^n \to \mathbb{R}^m be the linear map T(𝐱)=A𝐱T(\mathbf{x}) = A\mathbf{x}, and let rr be the number of pivots in an echelon form of AA. Then:

  1. TT is injective ⇔\iff A𝐱=0A\mathbf{x} = \mathbf{0} has only the trivial solution ⇔\iff the columns of AA are linearly independent ⇔\iff every column of AA is a pivot column, i.e. r=nr = n.
  2. TT is surjective ⇔\iff A𝐱=𝐛A\mathbf{x} = \mathbf{b} is consistent for every 𝐛∈ℝm\mathbf{b} \in \mathbb{R}^m ⇔\iff every row of AA contains a pivot position, i.e. r=mr = m.
  3. TT is bijective ⇔\iff m=nm = n and r=nr = n: AA is square and its echelon form has a pivot in every row and every column.
Since an echelon form has at most one pivot per row and at most one per column, r≤min(m,n)r \le \min(m, n). So an injective TT forces n≤mn \le m and a surjective TT forces n≥mn \ge m: a linear map ℝn→ℝm\mathbb{R}^n \to \mathbb{R}^m is never injective when n>mn > m, and never surjective when n<mn < m.

Throughout, note T(0)=A0=0T(\mathbf{0}) = A\mathbf{0} = \mathbf{0}.

(1) Suppose TT is injective and A𝐱=0A\mathbf{x} = \mathbf{0}. Then T(𝐱)=T(0)T(\mathbf{x}) = T(\mathbf{0}), so 𝐱=0\mathbf{x} = \mathbf{0}: only the trivial solution. Conversely, suppose 0\mathbf{0} is the only solution of A𝐱=0A\mathbf{x} = \mathbf{0} and T(𝐮)=T(𝐯)T(\mathbf{u}) = T(\mathbf{v}). By linearity, A(𝐮−𝐯)=A𝐮−A𝐯=0A(\mathbf{u} - \mathbf{v}) = A\mathbf{u} - A\mathbf{v} = \mathbf{0}, hence 𝐮−𝐯=0\mathbf{u} - \mathbf{v} = \mathbf{0} and 𝐮=𝐯\mathbf{u} = \mathbf{v}. The second equivalence is the proposition of the previous section. For the third, A𝐱=0A\mathbf{x} = \mathbf{0} is always consistent, so by the uniqueness criterion its solution is unique exactly when every column of AA is a pivot column, which is to say r=nr = n.

(2) The first equivalence is the definition of surjectivity written out in matrix form: the outputs of TT are exactly the vectors 𝐛\mathbf{b} for which A𝐱=𝐛A\mathbf{x} = \mathbf{b} has a solution. If every row of AA contains a pivot position, every such system is consistent by the existence criterion. Conversely, suppose some row has no pivot. Let UU be an echelon form of AA, reached from AA by a sequence of row operations; its pivotless rows are zero rows at the bottom, so the last row of UU is zero. The augmented matrix (U∣𝐞m)(\,U \mid \mathbf{e}_m\,) therefore has bottom row (0⋯0∣1)(\,0 \;\, \cdots \;\, 0 \mid 1\,) and is inconsistent. Now undo those row operations, applying the reverse sequence to the whole of (U∣𝐞m)(\,U \mid \mathbf{e}_m\,): this restores AA on the left and produces some 𝐛\mathbf{b} on the right. Row operations preserve the solution set, so A𝐱=𝐛A\mathbf{x} = \mathbf{b} is inconsistent too, and 𝐛\mathbf{b} is not an output of TT. Finally, one pivot per row at most makes ``a pivot in every row'' the same as r=mr = m.

(3) By (1) and (2), TT is bijective exactly when r=nr = n and r=mr = m, which forces m=nm = n.

Example 3.21 (The three properties, read off three matrices)¶

Bijective. The flip matrix FF of the flip example is already in echelon form, with pivots −1,−1,1-1, -1, 1 in all three rows and columns. So r=3=m=nr = 3 = m = n and the flip is bijective — as geometry predicts: flipping twice returns every vector to where it started.

Surjective but not injective. Let A=(100010),T:ℝ3→ℝ2,T(x1x2x3)=(x1x2),A = \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \end{pmatrix}, \qquad T\colon \mathbb{R}^3 \to \mathbb{R}^2, \qquad T\begin{pmatrix} x_1 \\ x_2 \\ x_3 \end{pmatrix} = \begin{pmatrix} x_1 \\ x_2 \end{pmatrix}, the map that drops the third coordinate. It is in echelon form with r=2=mr = 2 = m: every row has a pivot, so TT is onto — any 𝐛∈ℝ2\mathbf{b} \in \mathbb{R}^2 is the image of (b1b20)T(\,b_1 \;\; b_2 \;\; 0\,)^{T}. But the third column has no pivot, and indeed every vector (00z)T(\,0 \;\; 0 \;\; z\,)^{T} maps to 0\mathbf{0}. No map ℝ3→ℝ2\mathbb{R}^3 \to \mathbb{R}^2 could have been injective: 3>23 > 2, so the corollary makes its columns dependent.

Injective but not surjective. Let B=(100100),S:ℝ2→ℝ3,S(x1x2)=(x1x20),B = \begin{pmatrix} 1 & 0 \\ 0 & 1 \\ 0 & 0 \end{pmatrix}, \qquad S\colon \mathbb{R}^2 \to \mathbb{R}^3, \qquad S\begin{pmatrix} x_1 \\ x_2 \end{pmatrix} = \begin{pmatrix} x_1 \\ x_2 \\ 0 \end{pmatrix}, which lays the plane inside space as the xyxy-plane. Both columns are pivot columns, so r=2=nr = 2 = n and SS is one-to-one; but the third row carries no pivot, and 𝐞3\mathbf{e}_3 is not an output.

Remark 3.22 (Looking ahead)¶

The correspondence between matrices and linear maps is the conceptual heart of the course. From now on, every question has two faces: an algebraic one about a matrix, and a geometric one about a map. Next week we exploit this dictionary: composing maps will give us matrix multiplication, and undoing a map — possible for exactly the bijective maps characterized above — will give us the inverse matrix.
